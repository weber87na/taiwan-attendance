# 2026 年勞健保與勞退費用試算

規則版本：`TW-INSURANCE-2026-v1`。官方資料查核日：2026-09-16。
支援日期為 2026-01-01 至 2026-12-31；其他年度拒絕計算，必須查核當年新表再更新。

## 適用範圍

`attendance.insurance.estimate_insurance` 計算一般本國全時受僱者，在同一雇主全月參加勞保、就保、職災保險、第一類受僱者健保及勞退新制的費用預估。呼叫端須先確認各項投保資格。輸入為可申報的月薪資總額，單位為整數新臺幣元，不是實領薪資；低於 2026 年最低月薪 29,500 元的輸入會拒絕。

部分工時、未足月任職、留職停薪、負責人、自營作業、職業工會、外籍工作者、公保身分、未參加普通勞保的受僱者、已領老年給付或不適用就保者及其他健保類別均不在本 API 範圍。不能僅憑輸入一個月薪，就判定這些人的資格或應扣款。

## 實作規則

| 制度 | 本版適用費率 | 員工／雇主／政府 | 分級表範圍 |
| --- | --- | --- | --- |
| 勞保普通事故 | 11.5% | 20%／70%／10% | 一般全時 11 級，29,500～45,800 元 |
| 就業保險 | 1% | 20%／70%／10% | 準用勞保分級表 |
| 職災保險 | 傳入公司核定總費率 | 0%／100%／0% | 21 級，29,500～72,800 元 |
| 健保一般保費 | 5.17% | 30%／60%／10% | 58 級，29,500～313,000 元 |
| 勞退新制 | 雇主至少 6% | 0%／100%／0% | 本 API 範圍內第 25～62 級，29,500～150,000 元 |

各制度都獨立使用官方逐級列出的金額查表，超過上限才以各自最高級計算。沒有把勞保上限誤套到健保或勞退，也沒有依少數級距做線性推算。勞退完整官方表含較低的級距，但本版不處理其適用身分，因此僅收錄本 API 所需的全時月薪範圍。

健保員工負擔先計算每一人的保費並四捨五入，再乘以本人加計費眷屬數；眷屬最多計 3 人。雇主及政府則依公告平均眷口 0.56、合計 1.56 人計算，不跟著員工實際眷屬數變動。例如投保金額 29,500 元，本人保費 458 元，本人加 3 眷口為 1,832 元，雇主為 1,428 元，政府為 238 元。[健保署 2026 年受僱者保費表](https://www.nhi.gov.tw/ch/cp-19418-9eefb-2576-1.html)

勞保與就保分開計算各方分攤並四捨五入至元後相加。金額計算使用 `Decimal`、`ROUND_HALF_UP`，不使用二進位浮點數或 Python 的偶數捨入來計算保費。

## 輸入與輸出

```python
from attendance.insurance import estimate_insurance

result = estimate_insurance(
    monthly_salary=40000,
    dependents=2,
    occupational_rate=0.002,  # 0.2%；只是範例，須改成公司核定總費率
    pension_rate=0.06,       # 6%，雇主提繳
    as_of="2026-09-16",
)
```

`occupational_rate` 與 `pension_rate` 為比例小數，`0.06` 代表 6%。職災預設 0.2% 只是介面示例，並非全國共同費率；核定總費率需包括上下班災害及適用的實績調整，系統不自行猜測行業。雇主勞退不得填低於 6%。[勞保局試算說明](https://www.bli.gov.tw/0014162.html)、[勞退條例第 14 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030020&flno=14)

輸出 `bases` 為各制度投保／提繳基數；`employee`、`employer`、`government` 各包含 `labor_insurance`、`employment_insurance`、`occupational_insurance`、`nhi`、`pension` 及 `total`，金額均為整數新臺幣元。`rates` 以十進位字串回傳，避免傳輸精度損失。另附 `scope`、`estimate_only`、`warnings`、`sources`、版本及日期，可直接 JSON 序列化。

員工的 `pension=0` 表示未計入個人自願提繳，並非勞退不必繳。雇主提繳不得從員工薪資轉扣。`employer.total` 包含勞退雇主成本，不能視為員工應扣款；政府補助也不是員工可領的現金。

## 為何仍可能與官方帳單不同

- 本版假設全月投保。勞就災保的實際加退保日、月中異動及按日計費，與健保計費時點並不相同；本版不進行日數攤提。
- 輸入月薪對應的試算級距，可能不同於已申報生效級距。工資組成、最近期間平均、調整申報時程與核定結果需由承辦人確認。
- 職災費率依投保單位核定；錯填費率會直接改變雇主估計成本。
- 健保眷屬的個別補助資格、附加保費、獎金或兼職補充保費均未實作；雇主補充保費亦未計入。
- 未納入勞退個人自提、工資墊償基金、所得稅、其他薪資扣款、補退收及機關更正。因此 `total` 僅是列示項目的小計，不能直接用來完成薪資結算或申報。

正式薪資扣繳應核對勞保局、健保署繳款明細及實際核定資料；這個模組提供透明、可測試的預估，不會向任何機關送出申報。
