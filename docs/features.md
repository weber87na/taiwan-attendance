## 接續優先順序

1. 在實際公司的工作規則與假勤制度確認後，補完特休給假期間、結轉、未休工資、補休及撤銷重算。
2. 擴充排班合規檢查：週期例休、連續出勤、輪班間隔、法定程序與協議紀錄。
3. 將規則試算接到可覆核的薪資草稿，再加入完整保費計算與申報格式。
4. 補上企業登入、代理與多層簽核、個資保存政策、部署與監控。

規則改版應新增有效期間及官方依據、補齊邊界測試，保留歷史版本；不得直接用新費率覆算舊月份。
