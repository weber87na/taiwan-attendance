# 臺灣行事曆與排班規則

核對日期：2026-09-16。僅支援已核對的 **2026 年**，其他年度明確拒絕，不以固定月日或推算農曆冒充已核實資料。

## 資料範圍

`data/calendar-2026.json` 分別保存 16 個全國性國定假日、政府機關 6 筆補假，以及本專案的固定班制。全年日期由標準函式庫生成，並核對政府日曆全年 120 個免出勤日、無補行上班日。5 月 1 日已是全國性國定假日；2025 年新制增列的小年夜、教師節、10 月 25 日紀念日及行憲紀念日均已納入。

預設班制為週一至五每日正常工時 8 小時、週六休息日、週日例假。這是示範政策，勞基法並未限定休息日或例假必須落在週六、日。輪班、變形工時及其他班制必須另用實際班表判斷。

## 政府日曆與勞工補假分離

民間不能直接把行政機關補假日當成每位員工的法定休假日期。國定假日碰到原約定休息日或例假，仍須另給補假，日期由勞雇協商。國定假日與工作日調移亦應取得個別勞工同意，明確保留來源日與對調日。

因此，`calendar_month(year, month)` **不會自動啟用政府補假**。`proposed_substitutions` 顯示固定週末班制的參考日期，原日期仍為 `weekday`，`requires_agreement` 為 `true`。這不免除公司的補假義務；人資應與員工確認後登錄實際排班並保存協商證明。本日曆函式本身不修改班表、不計薪。

| 原國定假日 | 政府補假／固定週末參考日 | 民間狀態 |
| --- | --- | --- |
| 2/15 小年夜（週日） | 2/20 | 須協商 |
| 2/28 和平紀念日（週六） | 2/27 | 須協商 |
| 4/4 兒童節（週六） | 4/3 | 須協商 |
| 4/5 清明節（週日） | 4/6 | 須協商 |
| 10/10 國慶日（週六） | 10/9 | 須協商 |
| 10/25 紀念日（週日） | 10/26 | 須協商 |

參考補假配置會先保留所有國定假日，再避開週末及已使用的補假日。小年夜的補假必須越過 2/16–2/19，落於 2/20；兒童節與清明節各有一天補假，不合併扣掉一天。

國定假日撞週末時，當日 `kind` 保留 `rest_day` 或 `regular_day_off`，並以 `statutory_holiday` 保存節名。已協商的補假日才呈現 `national_holiday`，避免休息日與例假的出勤規則被錯誤覆蓋。

## Python 介面

```python
from attendance.calendar_tw import calendar_month

# 僅展示已核對國定假日、週休與待協商補假建議。
month = calendar_month(2026, 2)

# 呼叫端已有個別員工協商紀錄時，可明確傳入。
# 此選用參數不代表網站已建置協商證明簽核流程。
month = calendar_month(
    2026, 2,
    agreed_substitutions={"2026-02-15": "2026-02-23"},
)
```

`days` 逐日提供 `date`、`name`、`kind`、`is_holiday`、`source`，並附上原節日、已協商補假來源、待協商建議及政府當日是否放假的參考欄位。`normal_working_hours` 僅表示此班制的應排正常工時，不是打卡或薪資結果。頂層 `warnings` 應在前端展示。

補假只能指定其他工作日，不能落在週末、另一個國定假日、另一筆補假或未核對年度。函式接收一部分已協商資料時，其餘補假保留待處理狀態；`pending_substitution_count_year` 可供人資追蹤。完成全部 6 筆示範補假後，全年有 16 天具國定假日性質的免出勤日，加上 104 個週休日共 120 日。未協商前僅列出原班制與已確定節日，不應拿畫面上的免出勤總數當作最終年度休假配額。

## 需依員工或事件另處理的情形

- 原住民族歲時祭儀須依適用身分、族別及官方公告日期辦理，不能對所有員工套固定三日。
- 投票日取決於指定放假公告、個人投票資格及當天原班表；原本免出勤者不因投票日另得補假。
- 天然災害停班資訊不是自動新增的國定假日，應依工作地點、居住地點、通勤及勞動部相關措施處理。
- 公司額外福利假、員工國定假日調移與輪班，須保留獨立排班和同意紀錄。
